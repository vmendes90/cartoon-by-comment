How it works

  1. Type one sentence

    Open Claude Code in an empty folder and say what your cartoon is about. Half an idea is enough: "a houseplant that wants to see the world".

  2. Answer one question

    "You decide everything", or "Ask me at 3 points". That is the only question. You can switch at any time.

  3. It builds and checks

    Premise, character, look, script, a free voice, sound. A reviewer agent with fresh eyes checks every cut, and built-in checks keep the hero big and the captions clear. Every choice goes into bible.md with its reason, so you can change it later.

  4. You post. Paste the comments.

    You get a vertical MP4 (1080x1920), a cover, a caption and a pinned comment. You post it. When the vote closes, paste the comments. It counts them and builds Day 2.

Questions

Does it work on Windows and Mac?

Yes, both. The free voice works on each, using the voices built into Windows and macOS. On Windows the skill also needs Git (for Git Bash); it checks and tells you.

Do I need to know how to code?

No. Claude writes all the code. You give the idea and, if you want, notes like "make the ears bigger" or "use the other voice".

I have never used a terminal. Can I do this?

Yes. You type one command to start Claude Code, then talk to it in plain English. The skill gives you the install commands and runs them after you say "go".

Does it cost anything extra?

You need Claude Pro ($20/month) or higher, which includes Claude Code. Everything else is free: Node, Python, ffmpeg, the renderer and the voice. A paid voice is optional, and the skill always asks before spending any money.

What voice does it use?

The free voice built into your computer. It is fine for drafts and it sounds robotic. Before you post, you can keep it, record your own voice, or pay for a voice service. The skill shows the cost and waits for your yes first.

Can I use my own character?

Yes. Describe it in your first sentence, or pick "Ask me at 3 points" and shape it at the plan. Claude draws it in code, and you can correct anything later. It will not copy famous characters, brands or a real person's face.

How long does an episode take?

A first episode is a heavy session, about half an hour once the tools are installed. Later days reuse the character and sets. All progress lives in files in your series folder, so you can stop and continue in a new session.

How do updates work?

Updates are free. When there is a new version, download it again from your Polar purchase page and copy the new folder over the old one.

Can I monetize the videos I make?

Yes, they are yours. The manual explains the AI labels each platform asks for and which free voices and sounds you can use commercially.

What if nobody votes?

The manual has a section for that: easy one-word questions, your own pinned vote comment, and an honest way to decide on screen when only a few people vote.

Is this a get-rich course?

No. It is a tool and a production method. It does not promise views, followers or income.
